🚀 INSTALLATION IN 3 STEPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Install dependencies
────────────────────────────────────────────────────────────────
$ npm install

This will install all necessary project dependencies.


STEP 2: Configure TMDB Access Token
────────────────────────────────────────────────────────────────
1. Get your free Access Token at:
   https://www.themoviedb.org/settings/api

2. Open the .env file in the project root

3. Replace the line:
   VITE_TMDB_ACCESS_TOKEN=
   
   With:
   VITE_TMDB_ACCESS_TOKEN=your_access_token_here

NOTE: Use the "Read Access Token" (JWT) from TMDB


STEP 3: Run the application
────────────────────────────────────────────────────────────────
$ npm run dev

The application will be available at:
http://localhost:5173

🆘 COMMON PROBLEMS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Error: "TMDB API Error: 401"
→ Your Access Token is not configured correctly
→ Verify that you're using the "Read Access Token" (JWT)
→ Check the .env file and restart the server

Error: "Cannot find module"
→ Dependencies are not installed
→ Run: npm install

Blank page
→ Open browser console (F12)
→ Look for errors and verify configuration
